# 🌀 দিনচক্র — রুটিন, অ্যালার্ম ও লাইফস্টাইল অ্যাপ

তিনটি রুটিন অ্যাপের সব ইউনিক ফিচার একত্রিত করে তৈরি সিঙ্গেল-ফাইল ওয়েব অ্যাপ (`index.html`)। কোনো সার্ভার বা বিল্ড লাগে না — ফাইলটি ব্রাউজারে খুললেই চলবে।

## ফিচারসমূহ
- 🏠 হিরো ড্যাশবোর্ড: লাইভ ঘড়ি, পরবর্তী কাজের কাউন্টডাউন, প্রোগ্রেস রিং
- 🕐 ২৪ ঘণ্টার SVG দিনচক্র ডায়াল — পুরো দিনের রুটিন এক নজরে
- 🔔 অ্যালার্ম ইঞ্জিন: শব্দ + ভাইব্রেশন + নোটিফিকেশন, আগাম সতর্কতা (৫/১০/১৫/৩০ মিনিট), ৫ মিনিট স্নুজ, টেস্ট অ্যালার্ম
- 📋 সম্পূর্ণ এডিটেবল রুটিন: কাজ ও খাবার যোগ/সম্পাদনা/মুছে ফেলা, সময় ও স্থায়িত্ব পরিবর্তন
- 📅 প্রতিটি কাজের জন্য গুগল ক্যালেন্ডারে প্রতিদিনের রিমাইন্ডার লিংক
- 📝 নোট: রিমাইন্ডার ও পিনিং সহ, সার্চ সুবিধা
- 💧 পানি ট্র্যাকার, 😊 মুড ট্র্যাকার, 💻 দৈনিক বিড লক্ষ্য, ⭐ পয়েন্ট ও 🔥 স্ট্রিক
- 📈 গত ৭ দিনের অগ্রগতি চার্ট
- 🌬️ ব্রিদিং রিলাক্স বিরতি (৩ মি ২০ সে)
- 🌅 Wake Lock (স্ক্রিন জাগিয়ে রাখা), 🎨 ডার্ক/লাইট/সিস্টেম থিম
- 💾 JSON ব্যাকআপ এক্সপোর্ট/ইমপোর্ট

## ব্যবহার
`index.html` ফাইলটি যেকোনো ব্রাউজারে খুলুন। ফোনে ইনস্টল করতে Chrome মেনু (⋮) → "Add to Home screen" ব্যবহার করুন। অ্যালার্ম নোটিফিকেশনের জন্য একবার অনুমতি দিন।
